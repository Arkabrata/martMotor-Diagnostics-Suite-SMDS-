SmartMotor Diagnostics Suite (SMDS)
AI-Powered Motor Health Monitoring & Fault Detection System

SmartMotor Diagnostics Suite (SMDS) is a complete end-to-end predictive maintenance system built to detect anomalies in electric motors using raw vibration & acoustic sensor data sampled at 3200 Hz.

The system converts multi-axis sensor signals into engineered features and uses an XGBoost classifier to detect whether a motor is healthy or faulty with high accuracy.

SMDS is designed as an industrial-grade reference project for:

Condition Monitoring

Predictive Maintenance (PdM)

Vibration Analytics

Time-Series ML

Mechanical + AI use cases
